简便运算公式回顾

常用简便运算方法：

  • 加法交换律：a + b = b + a
  • 加法结合律：(a + b) + c = a + (b + c)
  • 乘法交换律：a × b = b × a
  • 乘法结合律：(a × b) × c = a × (b × c)
  • 乘法分配律：a × (b + c) = a × b + a × c
  • 减法的性质：a - b - c = a - (b + c)
  • 除法的性质：a ÷ b ÷ c = a ÷ (b × c)
  • 凑整法：将数凑成整十、整百的数
